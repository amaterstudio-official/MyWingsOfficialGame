# MyWings 2026 – Development

This document provides an overview of the development process, technologies and current direction of MyWings 2026.

MyWings 2026 is independently developed by **Amater Studio**.

---

## Development Overview

MyWings 2026 is an independent flight simulator built using **Unreal Engine 5**.

The project is developed with the goal of creating an immersive flight simulation experience, with a focus on aircraft flight physics, interactive flight systems and an expanding world.

Development is currently in the early Pre-Alpha stage.

## Technology

The project currently uses the following technologies:

| Technology | Purpose |
|---|---|
| Unreal Engine 5 | Main game engine |
| Cesium for Unreal | World and environment integration |
| GitHub | Project documentation and development updates |

Additional technologies and tools may be introduced during development.

## Main Development Areas

Development is focused on several key areas.

### Aircraft and Flight Physics

- Aircraft movement and flight behavior
- Flight controls
- Takeoff, flight and landing mechanics
- Future aircraft systems

### World and Environment

- 3D world integration
- Environment improvements
- World loading and performance
- Future airport and environment development

### User Interface

- Main menu
- In-game interface
- Camera controls
- User experience improvements

### Performance and Stability

- Performance optimization
- Bug fixing
- Compatibility improvements
- General stability improvements

---

## Current Development Priorities

The current development focus is on preparing the first playable public version.

Main priorities include:

1. Completing the main menu and game startup flow.
2. Improving the first aircraft and flight experience.
3. Improving world loading and performance.
4. Fixing known bugs and technical issues.
5. Testing and preparing the first public build.

---

## Development Versions

MyWings 2026 follows a version-based development process.

The project uses the following general version structure:

- **0.0.x** – Early Pre-Alpha development and initial improvements.
- **0.1.x** – Further development of the core simulator.
- **0.2.x and beyond** – Expansion of aircraft and simulator features.
- **0.8.x–0.9.x** – Beta testing and stabilization.
- **1.0.0** – Planned full release.

For more information, see [ROADMAP.md](ROADMAP.md).

## Testing

Testing is an important part of the development process.

Development builds are tested to identify:

- Gameplay and control issues
- Aircraft behavior problems
- Performance limitations
- World loading issues
- User interface bugs

Early development builds may contain unfinished or experimental features.

---

## Bug Reports and Feedback

Feedback is welcome and helps identify areas that need improvement.

If you encounter a bug or technical issue, please report it through GitHub Issues.

When submitting a report, include:

- A clear description of the issue
- Steps to reproduce the problem
- Your system specifications, when relevant
- Screenshots or videos, if available
